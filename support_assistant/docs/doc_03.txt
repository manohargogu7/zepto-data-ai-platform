Orders can be cancelled from the 'My Orders' section of the Zepto app up to the point when the order status changes to 'Out for Delivery'. Once the order is out for delivery, cancellation is no longer possible. If an order is cancelled before dispatch, the full amount is automatically refunded to the original payment method within 3–5 business days. Customers may also contact support via the in-app chat to request cancellation before dispatch.
